## English

Prevent loss of access after external registration: before unlinking the last provider, confirm a local Joomla password or add another provider. A profile link lets signed-in members set that password. Removal requires a protected confirmation; previously revoked links are not restored automatically.

Simplify Joomla-to-Joomla setup: choose the Joomla provider and enter the master address, display name and credentials. OpenID Connect endpoints are prepared automatically. The master can generate credentials and display the secret once after saving.

Also clear a stale Joomla relinking return that could display an expired-request message after a normal logout.

Install **pkg_identitymanager-1.0.4.zip**, or use Joomla’s updater. The same package serves master and client sites. Interface and documentation are available in French and English.

## Français

Évite de perdre l’accès à un compte créé par connexion externe : avant de délier le dernier fournisseur, confirmez un mot de passe Joomla local ou ajoutez un autre fournisseur. Un lien ouvre le profil pour définir ce mot de passe pendant la session. La suppression demande une confirmation protégée ; les anciens liens révoqués ne sont pas restaurés automatiquement.

Relier deux Joomla devient plus simple : choisissez le fournisseur Joomla et saisissez l’adresse du maître, le nom affiché et les identifiants de liaison. Les adresses OpenID Connect sont préparées automatiquement. Le maître peut générer les identifiants et afficher le secret une seule fois après l’enregistrement.

Corrige aussi un ancien retour de réassociation conservé par Joomla, qui pouvait afficher une demande expirée après une déconnexion normale.

Installez **pkg_identitymanager-1.0.4.zip**, ou utilisez la mise à jour Joomla. Le même package sert au maître et au client. Documentation et interface en français et anglais.
