## Français

Choisissez la page affichée après une connexion externe : accueil, lien de menu existant ou URL du site. Ce réglage se trouve dans le module Connexion, onglet Connexions externes, et s’applique notamment aux connexions GitHub, Google et Joomla. L’accueil est choisi par défaut. La destination est conservée lorsqu’un compte local existant doit être confirmé ; l’ajout d’un fournisseur depuis un compte déjà connecté revient à Mes connexions externes.

Le consentement du site maître décrit désormais les informations demandées en langage courant : identifiant de compte, nom, nom d’utilisateur, adresse e-mail et état de vérification. Il précise que le mot de passe n’est pas partagé. Les textes sont disponibles en français et en anglais.

Installez **pkg_identitymanager-1.0.5.zip**. Le même package sert au maître et au client et conserve les réglages et identités liées lors de la mise à jour. Tant que le dépôt est privé, téléchargez le ZIP avec votre accès GitHub et installez-le manuellement ; le flux public de mise à jour Joomla reste indisponible.

[Guide français](https://github.com/YGomiero/identitymanager-joomla/blob/main/docs/installation.fr.md) · [Signaler un problème](https://github.com/YGomiero/identitymanager-joomla/issues)

## English

Choose the page displayed after external sign-in: home page, an existing menu item or a URL on the same site. Configure it in the Login module’s External sign-in tab for providers including GitHub, Google and Joomla. The home page is the default. The destination is preserved when an existing local account needs confirmation; linking another provider while already signed in returns to My external connections.

The master consent screen now describes the requested information in plain language: account identifier, name, username, email address and verification status. It explains that the password is not shared. French and English translations are included.

Install **pkg_identitymanager-1.0.5.zip**. The same package serves master and client sites and retains settings and linked identities during an upgrade. While the repository is private, download the ZIP with your GitHub access and install it manually; the public Joomla update feed remains unavailable.
