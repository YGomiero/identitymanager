## Français

Corrige le parcours de réassociation d’une identité externe : après une déliaison, un retour GitHub répété ou un second clic reprend la confirmation du compte Joomla local au lieu d’afficher une erreur de session. Le code OAuth n’est pas rejoué et la liaison reste désactivée jusqu’à la connexion au compte local d’origine.

Le formulaire de confirmation ne propose plus de relancer la connexion externe. Les messages précisent le site concerné et indiquent comment définir un mot de passe local avec « Mot de passe perdu ? ». Les demandes expirent après dix minutes.

Lorsqu’un compte local possède déjà la même adresse e-mail, le site demande sa connexion puis termine la liaison automatiquement. Un lien « Mes connexions externes » apparaît dans le module de connexion et sur le profil, sans élément de menu à créer.

Installez **pkg_identitymanager-1.0.3.zip**, ou utilisez la mise à jour Joomla, sur les sites maîtres et clients.

[Documentation française](https://github.com/YGomiero/identitymanager-joomla/blob/main/README.fr.md) · [Signaler un problème](https://github.com/YGomiero/identitymanager-joomla/issues)

## English

Fix external identity relinking: after unlinking, repeated GitHub callbacks or clicks resume the local Joomla account confirmation instead of showing a session error. The OAuth code is not replayed and the link remains disabled until the original local account signs in.

The confirmation form no longer offers another external sign-in. Messages identify the receiving site and explain local password recovery. Pending requests expire after ten minutes.

When a local account already has the same email, the site asks for local sign-in and then completes linking automatically. My external connections is accessible from the login module and profile without creating a menu item.

Install **pkg_identitymanager-1.0.3.zip**, or use Joomla's updater, on master and client sites.
