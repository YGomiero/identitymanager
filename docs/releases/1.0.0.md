## English

First packaged release for Joomla 6 / PHP 8.3+. One package for client/master roles, full French/English UI and documentation, Hybridauth providers, validated OIDC, PKCE, registration controls, provider icons, log CSV/purge/retention and checksummed Joomla updates.

Install **pkg_identitymanager-1.0.0.zip**, not the source archives. Real GitHub and Joomla flows were tested; live Google and self-hosted WordPress remain unverified.

[Documentation FR](https://github.com/YGomiero/identitymanager/blob/main/README.fr.md) · [English documentation](https://github.com/YGomiero/identitymanager#readme) · [Validation](https://github.com/YGomiero/identitymanager/blob/main/docs/validation.fr.md)

## Français

Première version distribuable d’Identity Manager pour Joomla 6 / PHP 8.3+.

- Même package pour les rôles client et maître Joomla.
- Interface et documentation complètes en français et anglais.
- GitHub / Google via Hybridauth 3.13.0 ; client OAuth/OIDC et maître Joomla avec PKCE.
- Respect de la fermeture des inscriptions Joomla ; protection des comptes administrateurs.
- Logos, favicons configurables, export CSV, vidage et conservation des journaux.
- Flux de mise à jour Joomla et empreintes des archives.

Installez **pkg_identitymanager-1.0.0.zip**. Les archives « Source code » ne sont pas installables dans Joomla. Google réel et WordPress auto-hébergé ne sont pas validés ; les parcours GitHub et Joomla ont été testés.
